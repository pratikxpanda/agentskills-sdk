    Azure providers

    The agentskills-azure package groups Azure-backed providers under the agentskills_azure namespace. Each service has its own module and optional SDK dependencies.

    Blob Storage¶

    pip install "agentskills-azure[blob]"

    Grant the provider's Azure identity read access to the target container. The provider uses DefaultAzureCredential unless you pass an asynchronous credential explicitly.

    The Blob quick start shows the required uploaded directory layout, authentication setup, and complete async usage.

    The provider supports discovery, resource listing, and complete raw-file access. Reads are bounded by max_file_bytes, and canonical paths are returned relative to each skill directory.

    Azure Files¶

    pip install "agentskills-azure[files]"

    The Files quick start shows the SMB directory layout and complete async usage with explicit backup intent.

    The provider uses async FileREST access to SMB shares. Token credentials require the explicit token_intent="backup" opt-in, which bypasses file and directory ACLs subject to Azure RBAC. Provision the required backup-read permissions at the narrowest applicable scope.

    Directory discovery and recursive listing do not download file contents. Downloads preserve raw bytes and enforce max_file_bytes. Use max_files and max_depth to bound traversal. NFS shares, unsafe paths, and reparse points are rejected. The provider closes its own default credential but leaves injected async credentials open.

    API Reference¶

    agentskills_azure.blob.AzureBlobSkillProvider ¶

    Bases: SkillProvider

    Read and discover skills stored as blobs beneath a container prefix.

    A skill is a virtual directory containing SKILL.md and optional files. The provider uses the Azure SDK's asynchronous clients and defaults to DefaultAzureCredential. Call :meth:aclose when finished, or use the provider as an asynchronous context manager.

    Parameters:

    Name Type Description Default
    account_url str

    Blob service endpoint, such as https://account.blob.core.windows.net.

    		 required
    container_name str

    Container holding the skill blobs.

    		 required
    prefix str

    Optional path prefix inside the container.

    		 ''
    credential AsyncTokenCredential | None

    Optional asynchronous Azure credential. When omitted, the provider creates and owns a DefaultAzureCredential.

    		 None
    max_file_bytes int

    Maximum size of any file read by the provider.

    		 DEFAULT_MAX_FILE_BYTES

    Raises:

    Type Description
    ValueError

    If the container name, prefix, or size limit is invalid.

    agentskills_azure.files.AzureFilesSkillProvider ¶

    Bases: SkillProvider

    Read skills from directories in an Azure Files SMB share.

    Uses the async FileREST SDK, not a mounted filesystem. Token authentication requires an explicit token_intent="backup" opt-in because it bypasses file ACLs subject to Azure RBAC. NFS shares and reparse points are rejected.

    Parameters:

    Name Type Description Default
    account_url str

    File service endpoint, such as https://account.file.core.windows.net.

    		 required
    share_name str

    SMB share containing the skill directories.

    		 required
    prefix str

    Optional directory beneath which skills are stored.

    		 ''
    credential AsyncTokenCredential | None

    Caller-owned async credential. Defaults to an owned DefaultAzureCredential.

    		 None
    token_intent Literal['backup'] | None

    Must be "backup" to acknowledge FileREST token semantics.

    		 None
    max_file_bytes int

    Maximum bytes returned by a file read.

    		 10 * 1024 * 1024
    max_files int

    Maximum files listed in one skill.

    		 10000
    max_depth int

    Maximum nested directory depth inside one skill.

    		 64

    Raises:

    Type Description
    ValueError

    If the share, limits, or token intent are invalid.
    ResourceNotFoundError

    If the prefix contains an unsafe path.
