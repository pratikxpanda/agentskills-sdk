---
title: Retired LangChain Integration
description: Retirement notice for agentskills-langchain.
---

`agentskills-langchain` was deprecated in v0.6 and is removed from v0.7 releases.
The [v0.6.0 source](https://github.com/pratikxpanda/agentskills-sdk/tree/v0.6.0/packages/integrations/agentskills-langchain)
and existing wheels remain available, without future framework compatibility guarantees.

Read the [native-only migration guide](../mcp-migration.md). The old framework-owned
MCP examples rely on removed legacy tools and are not v0.7 replacements.
