---
title: Filesystem Provider
description: Read skills from a local directory with bounded, lossless file access.
---

Loads skills from a local directory.

```bash
pip install agentskills-fs
```

The root contains one directory per skill, each with a valid `SKILL.md`. For a complete
directory layout, sample skill, and runnable example, see the
[package guide](https://github.com/pratikxpanda/agentskills-sdk/blob/main/packages/providers/agentskills-fs/README.md#usage).
