# Format Adapters (`agentskills-adapters`)

Import common agent instruction formats as native `agentskills-core` `Skill` objects.

```bash
pip install agentskills-adapters
```

Supported sources include `AGENTS.md`, Copilot instructions, Cursor `.mdc` rules,
and Claude-style folders containing `SKILL.md`. Use `agentskills init --from`
to convert one source into an editable native skill.
